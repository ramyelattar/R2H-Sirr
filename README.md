# سِرّ — R2H Sirr

**M8 · Egyptian-first Android experience · Source under review**

لعبة خاصة للبالغين (+18) على Android، بلغتها واجهة مصرية عامية، بتجارب للشريكين ولمّة الصحاب، نرد، اختبارات، كشط، وهمسات. كل لعبة لازم يكون فيها اختيار واضح للمشاركة وحق التخطي والتوقف.

## الحالة الحقيقية

- **M7:** تم تجميع Debug APK على جهاز المالك يوم 24 أكتوبر 2026، وتثبيته بنجاح. الصور الفعلية كشفت ضعفًا في المظهر وتجربة اللعب، فبدأت إعادة التصميم M8.
- **M8:** تعديل كبير للواجهات وتوليد المحتوى على فرع `feature/m8-egyptian-experience`. **لم يتم بعد تجميعه أو اختباره على هاتف.**
- لم يُدمج M8 في `main`. Pull Request في وضع Draft: https://github.com/ramyelattar/R2H-Sirr/pull/6
- جميع أرقام الاختبارات القديمة تخص مراحلها، وليست إثباتًا أن M8 تم تجميعه أو اجتاز اختبارات الأجهزة.

## محتوى M8

- **230 تحديًا مصريًا**: 130 للشريكين و100 للمجموعة، موزعة على خمس درجات. اتراجع واتكتب كامل بنك التحديات بنبرة مصرية.
- **175 سؤالًا مصريًا**: سبعة مواضيع × 25 سؤالًا بثلاث إجابات لكل سؤال. المحتوى ترفيهي للحوار، مش اختبار نفسي أو درجة توافق علمية.
- اختيار الجولات القصيرة يفضل ألعاب البداية المصاغة كمواقف واختيارات ومفاجآت، مع منع تكرار التحديات داخل الجلسة.
- الأصل القانوني للمحتوى: نصوص عربية مبتكرة داخل المشروع، وليس نسخ النصوص أو الصور من موقع خارجي.

## الواجهة وتجربة اللعب

- دخول للبالغين بالموافقة الذاتية على العمر والمشاركة، مش تحقق هوية مستقل.
- تصميم غامض بألوان أسود وخمري وشامبانيا. شاشة بداية واضحة، زر رئيسي واحد، وقوائم أقصر.
- الجولات المحلية: اختار المود والجولات، مع إخفاء الاختيارات المتقدمة، ثم الموافقة الفردية لكل مشارك قبل البدء.
- نرد مرسوم داخل Compose بتأثير ثلاثي الأبعاد تقريبي، رمية قصيرة، واختيارات إضافية اختيارية. **مش محرك 3D حقيقي.**
- كشط باللمس ورسائل جاهزة أو مخصصة، وهمسات بخطوات عرض متتابعة، واختبارات سؤال واحد في كل خطوة.
- مؤثرات الصوت والاهتزاز والحركة اختيارية؛ تراعى إعدادات تقليل الحركة.
- الجلسات البعيدة تستخدم خادم HTTPS/WSS مستقلًا غير منشور تلقائيًا بواسطة GitHub.

## بروتوكول الجلسات

- **contentVersion = 4**، **protocolVersion = 4**. يجب تحديث **الخادم وAndroid والويب معًا**؛ يُرفض العميل الأقدم بدل خلط بنوك الأسئلة.
- رسائل الجلسة والبطاقات والوسائط تُرسل مشفرة بمفتاح مشترك في رابط الدعوة. نتائج الاختبارات الثنائية تُحسب باستخدام وسوم HMAC لا بإرسال الاختيارات الأصلية.
- التشفير المشترك لا يثبت هوية كل مشارك بصورة مستقلة ولا يمنع حامل رابط الدعوة من استخدامه. الملفات المعروضة على جهاز المستلم قد تُنسخ أو تُصوَّر خارجيًا.
- غرف الخادم مؤقتة في الذاكرة، وإعادة تشغيل الخادم تفقد الغرف. تسليم بطاقات العرض مرة واحدة ليس إثبات مشاهدة.

## المصدر الموحد للمحتوى

- `content/challenges_ar_v2.json` — بنك التحديات؛ الاسم تاريخي لكن الإصدار الداخلي الآن **4**.
- `content/quizzes_ar_v4.json` — بنك الأسئلة الأساسي v4.
- `tools/generate_content_v2.py` — اسم تاريخي لمولد Kotlin وJSON المستخدم حاليًا.
- `app/src/main/java/com/r2h/sirr/core/AdultChallengesV2.kt` و`EgyptianQuizCatalog.kt` — ملفات Kotlin المولدة.
- `backend/public/challenges.json` و`quizzes.json` — الملفات المولدة للويب والخادم.

### توضيح M20: المحتوى النشط مقابل الأرشيف

- **المحتوى النشط:** `challenges_ar_v2.json` و`quizzes_ar_v4.json` (الإصدار الداخلي 4) هما المصدر المعتمد لشاشات Android وتجربة الويب/الجلسة البعيدة، ويتم توليد نسخ Kotlin والويب عبر `generate_content_v2.py`.
- **محتوى محفوظ لكنه غير مستخدم:** `content/additional_quizzes_ar_v2.json` (الإصدار الداخلي 3، يحتوي على 119 سؤالًا) ونسخته `MoreQuizzesV2.kt`؛ لا تحذفهما أو تدمجهما تلقائيًا في 175 سؤالًا.
- **عينات تاريخية:** `OriginalContent` داخل `GameLogic.kt` يحتوي على 21 سؤالًا نموذجيًا و12 تحديًا للشريكين و12 للمجموعة وقالب نرد. لا يمثل المحتوى المعروض حاليًا.
- **كود نشط يجب الحفاظ عليه:** `GameLogic.weightedFace` و`evenWeights` ونوعا البيانات `Question` و`Quiz`. الاختبارات الحالية تفحص `ExpandedQuizzes.packs` و`Challenges.deck` و`DiceCatalog.preset` بدلًا من الاعتماد على عينات `OriginalContent`.
- تدقيق مراجع المحتوى محفوظ في `docs/M19_CONTENT_USAGE_LEGACY_AUDIT.md`. تحديث M20 يغيّر الاختبارات والتوثيق وعلامات Deprecation فقط، **بدون تغيير نصوص المحتوى أو سلوك اللعب**.

لتحديث الملفات المولدة بعد تعديل المحتوى، شغّل:

```bash
python tools/generate_content_v2.py
python tools/generate_content_v2.py --check
```

اختبارات Node (لا تتطلب Gradle أو بناء Android):

```bash
cd backend
npm install
npm test
```

أُضيفت GitHub Actions لهذه الفحوصات، لكن أول تشغيل أعطى `startup_failure` بدون أي Jobs؛ **ده مش نجاح اختبارات**، ولازم مراجعة إعدادات Actions في المستودع.

## حدود الإصدار

M8 غير معتمد للتثبيت أو النشر النهائي حتى تنجح ترجمة Kotlin/Compose، واختبار شكل الشاشات بالعربي وRTL على أجهزة صغيرة، وتشغيل الألعاب والصوت والكشط والوسائط مع انقطاع الشبكة والتشفير بين Android والمتصفح. لا يُعتبر كود المصدر وحده إثبات تشغيل.

باقي تفاصيل مراحل M4–M7 التاريخية محفوظة داخل `docs/`. راجع `docs/M8_EGYPTIAN_UX.md` لنطاق التجديد ومعايير قبول M8.
